# 📊 Painel de Investimento Financeiro Imobiliário

Este projeto é uma planilha desenvolvida para auxiliar investidores a estruturarem e acompanharem suas alocações em Fundos de Investimento Imobiliário (FIIs), com base em perfis de risco e tipos de fundos.

---

## 🎯 Objetivo

Oferecer uma base estratégica para alocação de investimentos em FIIs, organizando os ativos conforme o perfil do investidor (ex: Conservador, Moderado) e tipo de fundo (ex: PAPEL, TIJOLO, HÍBRIDOS, FOFs).

---

## 🧩 Estrutura da Planilha

### 📄 Aba: Planilha2

Contém as seguintes colunas:

| Coluna         | Descrição                                                                                                      |
| -------------- | -------------------------------------------------------------------------------------------------------------- |
| **CHAVE**      | Identificador único do perfil + tipo de ativo. Ex: Conservador-PAPEL.                                         |
| **PERFIL**     | Perfil de risco do investidor. Pode ser: Conservador, Moderado, etc.                                          |
| **TIPOS DE FII** | Classificação dos FIIs: PAPEL, TIJOLO, HÍBRIDOS, FOFs.                                                      |
| **%**          | Proporção ideal de alocação para aquele tipo de ativo dentro do perfil.                                       |
| **Outras colunas** | Dados adicionais para montagem de alocação em outros perfis. Alguns campos contêm exemplos como Moderado-TIJOLO. |

> **Nota:** Os valores em % representam o quanto do capital total o investidor deveria alocar em determinado tipo de FII, baseado no perfil escolhido.

---

## 🧠 Perfis de Investidor

- **Conservador:** Prefere segurança, maior proporção em ativos estáveis como TIJOLO e PAPEL.
- **Moderado:** Busca equilíbrio entre risco e retorno, com diversificação maior.
- *(Outros perfis podem ser adicionados com base na estratégia do investidor.)*

---

## 💼 Como Usar

1. Abra a planilha no Excel ou Google Sheets.
2. Selecione o perfil de investidor com o qual se identifica.
3. Utilize os percentuais sugeridos para distribuir seu capital entre os tipos de FIIs.
4. Insira sua carteira real em outra aba (como a "APP", atualmente em branco) e compare com os percentuais ideais.
5. Atualize os dados conforme sua evolução de investimentos.
